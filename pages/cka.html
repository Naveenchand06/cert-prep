Exam-day routine

  1. Read the task's weight and run the ssh/context line it gives before anything else.
  2. Set the namespace: k config set-context --current --namespace=<ns>.
  3. Generate YAML with --dry-run=client -o yaml; look up fields with k explain.
  4. Debug in order: get → describe → logs → events.
  5. Verify the result the task asks for, then exit back to the base host.
  6. Skip anything over ~8 min, note it on the notepad, and come back to it.
